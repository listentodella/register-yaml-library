ERRDEVID, Device Configuration Register

The ERRDEVID characteristics are:

Purpose

Provides discovery information for the component.

Configuration

ERRDEVID is implemented only as part of a memory-mapped group of error records.

Attributes

ERRDEVID is a 32-bit register.

Field descriptions

Bits [31:22]

Reserved, RES0.

PFG, bit [21]
When RAS System Architecture v2 is implemented:

Common Fault Injection Mechanism. Describes whether any FEAT_RASSA_PFGCommon Fault Injection Mechanism registers are implemented in the same page as this register.

The value of this field is an IMPLEMENTATION DEFINED choice of:

PFGMeaning
0b0

Any FEAT_RASSA_PFGCommon Fault Injection Mechanism registers are implemented in the same page as this register.

0b1

Any FEAT_RASSA_PFGCommon Fault Injection Mechanism registers are implemented in a separate fault injection group page.

FEAT_RASSA_PFG_GRP implements the functionality identified by the value 0b1

Note

The value of this field does not indicate that any Common Fault Injection Mechanism registers are implemented by the nodes in this error record group. Software must use ERR<n>FR to discover whether each node implements Common Fault Injection Mechanism registers.

The value of this field does not indicate that any FEAT_RASSA_PFG registers are implemented by the nodes in this error record group. Software must use ERR<n>FR to discover whether each node implements FEAT_RASSA_PFG registers.

Accessing this field has the following behavior:

  • When ERRDEVID is part of a fault injection group, access to this field is RAZ/WI.
  • Otherwise, access to this field is RO.


Otherwise:

Reserved, RAZ.

Bit [20]

Reserved, RES0.

IRQCR, bits [19:16]

Interrupt configuration registers. Describes whether the interrupt configuration registers are implemented.

The value of this field is an IMPLEMENTATION DEFINED choice of:

IRQCRMeaning
0b0000

It is IMPLEMENTATION DEFINED whether any interrupt configuration registers are implemented.

0b0001

An IMPLEMENTATION DEFINED form of interrupt configuration registers are implemented.

0b0010

The recommended layout form of interrupt configuration registers are implemented, for simple interrupts.

0b0011

The recommended layout form of interrupt configuration registers are implemented, for message-signaled interrupts.

0b1111

Interrupt configuration registers are not implemented.

If this field reads as 0b0000, then it is IMPLEMENTATION DEFINED whether FEAT_RASSA_IRQCR_SIMPLE, or FEAT_RASSA_IRQCR_MSI, or neither are implemented.

FEAT_RASSA_IRQCRAll implementsother thevalues functionalityare identified by the valuesreserved. 0b0001, 0b0010, and 0b0011.

FEAT_RASSA_IRQCR_SIMPLE implements the functionality identified by the value 0b0010.

FEAT_RASSA_IRQCR_MSI implements the functionality identified by the value 0b0011.

From FEAT_RASSAv2, the value 0b0000 is not permitted.

All other values are reserved.

Accessing this field has the following behavior:

  • When ERRDEVID is part of a fault injection group, access to this field is RAZ/WI.
  • Otherwise, access to this field is RO.

NUM, bits [15:0]

Highest numbered index of the error records in this group, plus one. Each implemented record is owned by a node. A node might own multiple records.

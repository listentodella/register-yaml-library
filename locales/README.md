# Localized register text

本目录保存寄存器 YAML 的语言 sidecar。目录必须按语言标签和英文源路径镜像：

```text
locales/zh-CN/architecture/arm/m-profile/arm-cm33-system-registers.yaml
```

翻译流程见 [`../TRANSLATING.md`](../TRANSLATING.md)，格式见 [`../schema/register-yaml-translation-schema.md`](../schema/register-yaml-translation-schema.md)。不要在本目录复制完整寄存器结构。
